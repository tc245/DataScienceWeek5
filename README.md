# Practical 4: Modelling with categorical and count data in R

Practical materials for "Data Science for Geographers".

- `Practical_4_working_categorical_data.ipynb` is the practical notebook.
- `merged_data_counts.csv` is the dataset created at the end of Practical 1 with two extra columns: `smokers` and `pregnant_women`, the counts that `smoking_rate` is calculated from. The Poisson regression section needs them.

Keep the notebook and `merged_data_counts.csv` in the same folder. As in Practical 2, the notebook first removes the six datazones with more than 100 retailers per 1000 people.

The data are simulated: every datazone and value is fictional.

The notebook needs `tidyverse` and an R Jupyter kernel.
